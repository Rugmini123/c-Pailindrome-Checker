# Palindrome Checker 🔄

A C program that checks whether a given number is a palindrome.

## Features
- Reverses a number
- Compares original and reversed values
- Displays result

## Technologies Used
- C Programming

## How to Run
1. Compile the program
2. Enter a number
3. View result

## Example Output
Enter a number: 121  
Palindrome number
